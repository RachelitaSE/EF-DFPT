# EF-DFPT
Exact factorization density functional perturbation theory code analysis. Based on the paper: DOI: https://doi.org/10.1103/dmpv-zqdh

# EF-DFPT Analysis

This repository contains **analysis and post-processing tools** for the **EF-DFPT (Exact-Factorization Density-Functional Perturbation Theory) code**, which describes **non-adiabatic electron-phonon interactions in materials**.

The purpose of this repository is to analyze and interpret data generated by the EF-DFPT framework, as introduced and developed in our accompanying research paper.
The project provides:
- reusable Python utilities for loading and processing DFPT data
- scripts for producing publication-quality figures
- a clean, installable package structure suitable for long-term research use
---

## Overview

Electron-phonon interactions are commonly treated within the **Born–Oppenheimer (adiabatic) approximation**, where electronic and nuclear degrees of freedom are assumed to be separable. While this approach is often sufficient, **non-adiabatic effects** can play a crucial role in accurately describing electronic structure, band renormalization, lifetimes, and transport properties in materials.

The **Exact Factorization (EF)** formalism provides a rigorous framework to treat electron-nuclear coupling beyond the Born–Oppenheimer approximation by exactly factorizing the full electron-nuclear wavefunction. When combined with Density-Functional Perturbation Theory (DFPT), this approach enables a first-principles description of **non-adiabatic electron-phonon effects in solids**.

This repository focuses on the **analysis of EF-DFPT outputs**, allowing users to extract non-adiabatic corrections to electronic energies, wavefunctions, and derived quantities.

---

## Features

- Load DFPT data from `EF_data.h5` and `overlaps.h5`
- Construct k-paths from high-symmetry points
- Align band energies to the VBM
- Compare unperturbed, EF-corrected, and adiabatic band structures
- Analyze magnitude of second-order corrections vs band energy
- Visualize wavefunction overlap matrices near the band gap
- Clean `src/`-based Python package with documented API

⚠️ **Note:**  
This repository does **not** perform DFPT or EF-DFPT calculations itself. It is intended to be used **after** such calculations have been completed using the corresponding EF-DFPT implementation.

## Installation

Clone the repository and install in editable mode:

```
bash
git clone https://github.com/RachelitaSE/EF-DFPT.git
cd EF-DFPT
pip install -e .
```

### Dependencies
```
* Python ≥ 3.9
* numpy
* scipy
* matplotlib
* h5py
```
These are listed in `pyproject.toml` and installed automatically.

## Running the scripts
Run scripts *from the repository root* after installation:
```
python scripts/EF-bandstructure.py
python scripts/EF-energy_analysis.py
python scripts/EF-overlap-gap.py
python scripts/EF-overlap_all_kpoints.py
```
Each script:
* loads data from hard-coded paths (as in the original analysis)
* reproduces the original numerical and plotting behavior
* shows figures interactively using Matplotlib

## Using the Package in Python
You can also use the package directly in Python or notebooks:
```
from ef_dfpt.io import load_h5_data
from ef_dfpt.energies import normalize_energies
from ef_dfpt.kpoints import make_kpath
```
Example:
```
rk, occ, e0, e2, e2_adiab = load_h5_data("EF_data.h5")
e0 = normalize_energies(e0, occ)

```
## EF-DFPT HDF5 Output Structure

This section describes the structure and physical meaning of the HDF5 files
produced by the EF-DFPT code and consumed by the analysis tools in this repository.

The EF-DFPT workflow produces two primary output files relevant for post-processing:

* `EF_data.h5` — electronic energies adiabatic energy corrections and EF-DFPT energy corrections
* `overlaps.h5` — overlap matrices between unperturbed and EF-corrected wavefunctions
⚠️ Important:
This repository only reads and analyzes these files.
It does not generate them.

## 1. `EF_data.h5` — Exact factorization Corrections

`EF_data.h5` contains Kohn–Sham electronic structure data together with
adiabatic and non-adiabatic electron–phonon corrections computed within
the EF-DFPT formalism.
```
EF_data.h5
│
├── mf_header/
├── gkq_header/
├── gkq_mappings/
├── gkq_data/
│   ├── energies
│   └── frequencies
│
├── ef_header/
│   └── delta
│
├── corrections/
│   ├── 1st_order_corrections
|   |   Shape: (nk, nbnd, ns, ngk_max)
|   |   Type: complex128
|   |   Description: Contains the first-order prefactor to the wavefunction correction
│   ├── 1st_order_v_NA
|   |   Shape: (nq, nk, nbnd, nbnd)
|   |   Type: complex128
|   └── Description: The non-adiabatic 1st order additive potential matrix 
│
└── e2_corrections/
    ├── energy_corrections
    |   Shape: (nk, nbnd)
    |   Type: float64
    |   Description: non- adiabatic 2nd order energy correction term built from 4 terms listed bellow
    ├── e2_adiab
    |   Shape: (nk, nbnd)
    |   Type: float64
    |   Description: adiabatic 2nd order energy correction term following Guistino2017
    ├── e2_first_term
    ├── e2_second_term
    ├── e2_third_term
    └── e2_forth_term
```
### shape of the energy terms:
| Dataset          | Shape                  | Meaning                  |
| ---------------- | ---------------------- | ------------------------ |
| `e2_first_term`  | `(nq, nk, nbnd, nbnd)` | NA-FM term               | 
| `e2_second_term` | `(nq, nk, nbnd, nbnd)` | correction to NA-FM term |
| `e2_third_term`  | `(nq, nk, nbnd, nbnd)` | mixed two-phonon term    |
| `e2_forth_term`  | `(nq, nk, nbnd)`       | diagonal DW term         |   

## 2. `overlaps.h5` — Wavefunction Overlap Diagnostics
`overlaps.h5`` contains overlap matrices between unperturbed and
EF-corrected wavefunctions, evaluated at each k-point.

These overlaps are primarily used to:
* diagnose band mixing
* assess the validity of perturbative corrections
* visualize coupling near the band gap
### Structure
```
overlaps.h5
│
└── overlaps/
    ├── old_new
    │   Shape (full data): (nk, nbnd, nbnd)
    │   Shape (demo data): (nk, nbnd_window, nbnd_window)
    │   Type: complex128
    │   Description: Overlap between unperturbed (old) and
    │                EF-corrected (new) wavefunctions
    │
    └── new_new
        │   Shape (full data): (nk, nbnd, nbnd)
        │   Shape (demo data): (nk, nbnd_window, nbnd_window)
        │   Type: complex128
        │   Description: Overlap between EF-corrected wavefunctions

```
